## 第 0 轮探测结果（5090，2026-11-23）

- 三指拿方块示范成功。保持阶段每帧恰好 3 个接触点，每根手指一个：拇指在 +x 面，食指和中指在 −x 面，y 分别约为 −13 mm 和 +11 mm。
- 保持阶段法向力：拇指 6.31 N，食指 2.91 N，中指 3.40 N，满足拇指 = 食指 + 中指。物体 50 g，切向/法向力比约 0.02，说明握得远比需要的紧。
- 手指转子惯量取 0.003 时，合拢阶段的峰值和保持阶段相同，没有尖峰。
- 吞吐量：1024 个并行环境时 26.8 万环境步/秒（300 Hz 物理），每次读取接触 6 ms，建场景约 11–36 s。2000–3000 轮抓取的物理时间在分钟量级，瓶颈在逐步求解 SOCP。

## 设计问题：三点接触下，重量分担由静力学固定

每根手指只有一个点接触，没有扭转摩擦。三个接触点又在同一高度，绕 x 轴和 y 轴的力矩平衡就把每个接触点分担的重量完全定死了：对称放置时拇指 1/2，食指和中指各 1/4。于是每根手指的法向力都有下限，等于它分担的重量除以 μ。

分力器能自由分配的只有超出这个下限的"内力"（额外的夹紧力），没法把载荷从薄弱手指挪到另一根手指的下限以下。如果目标是"总力最小"，三根手指都正好停在各自下限上，风险约束要么不起作用，要么无解。测试 `test_three_point_grasp_fixes_weight_shares` 和 `test_probe_geometry_limits_the_shift` 用数字验证了这一点。

所以，只有在至少一种情况成立时，"力跟着薄弱区换边"才会出现：

1. **有防打滑余量（推荐）。** 打滑可以检测、可以挽回，捏坏不行。正好对应论文的核心洞察。具体做法：
   - 摩擦锥只按真实 μ 的保守下界设为硬约束；
   - 再按名义 μ̂ 加一个"防打滑余量"软约束，带惩罚；
   - 损伤约束是硬约束。

   这样薄弱一侧会先放弃余量，载荷转到别的手指。
2. **接触不止三个。** 例如每根手指有多个接触点、加上无名指，或者手掌参与。
3. **软指接触。** 允许扭转摩擦，真机的指腹就是面接触。但仿真里每指只有一个接触点，物理上提供不了这个力矩。
